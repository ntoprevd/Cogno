在多线程环境下，确保线程安全是 Java 开发的核心。synchronized 关键字通过 JVM 内部的 Monitor 锁机制实现原子性。

1. Synchronized 的作用

它主要用于解决多个线程在访问共享资源时产生的冲突问题，确保同一时刻只有一个线程执行特定代码块。

public synchronized void syncMethod() {\n    // 临界区代码\n}

2. 经典单例模式 (DCL)

以下是使用“双重检查锁定”实现的单例模式，通过 volatile 关键字禁止指令重排：

public class Singleton {\n    private static volatile Singleton instance;\n    private Singleton() {}\n\n    public static Singleton getInstance() {\n        if (instance == null) {\n            synchronized (Singleton.class) {\n                if (instance == null) {\n                    instance = new Singleton();\n                }\n            }\n        }\n        return instance;\n    }\n}
