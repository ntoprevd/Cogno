`synchronized` 是 Java 中的关键字，主要用于解决多线程环境下的资源竞争问题。它可以保证在同一时刻，只有一个线程可以执行特定的代码块或方法。

其核心特性包括：

  • 原子性：确保线程互斥访问。
  • 可见性：保证共享变量的修改对其他线程可见。
